# Anime Mysterious — Marching Character Battle

เกมต่อสู้วางแผนแนวอนิเมะ: **เรียกตัวละครจากฐานเรา → ตัวละครเดินไปตามเส้นทาง → หยุดสู้กับศัตรู → ป้องกันฐานให้ครบ 8 เวฟ** ใช้ตัวละครและฉากที่สร้างขึ้นใหม่

เวอร์ชันนี้เปลี่ยนจากป้อมยิงที่ยืนบนฐานหมายเลข เป็นกองกำลังตัวละครที่เดินออกจากฐานของเราเอง ทั้งฝ่ายเราและศัตรูมีหัว แขน ขา อาวุธ ท่าเดิน และเลือด สามารถโจมตีและล้มได้

## ดาวน์โหลดและเปิดเล่น

- [ดาวน์โหลด ZIP บน GitHub](https://github.com/Tarox46/paid/raw/refs/heads/main/roblox/AnimeMysterious.zip)
- [ไฟล์เกมบน GitHub](https://github.com/Tarox46/paid/blob/main/roblox/anime-mysterious/AnimeMysterious.rbxlx) — กด **Download raw file**

1. แตก ZIP แล้วเปิด `AnimeMysterious.rbxlx` ด้วย **Roblox Studio → File → Open from File**
2. กด **Play / F5** เพื่อเริ่มทั้ง Server Script และหน้าจอ LocalScript
3. กดการ์ด **Recruit** ด้านล่างเพื่อเรียกตัวละครเข้าทีม ตัวละครจะรอที่ฐานสีเขียวของเรา
4. กด **Start Wave** ตัวละครจะทยอยเดินจากฐานเราไปทางประตูม่วง ส่วนศัตรูเดินสวนมาจากประตูม่วง
5. เมื่อถึงระยะโจมตี ตัวละครจะหยุดต่อสู้ ศัตรูจะเดินเข้ามาโจมตีกลับได้
6. คลิกตัวละคร หรือใช้ปุ่ม **< / >** ในหน้าต่างทีม เพื่อดูเลือด อัปเกรด หรือขาย
7. รักษาเลือดฐานให้เหลือมากกว่า 0 จนจบเวฟ 8 เพื่อชนะ

แผนที่และตัวละครสร้างตอนกด Play จึงอาจเห็นฉากว่างในโหมดแก้ไข ไม่ต้องใช้ปลั๊กอิน เปิด HTTP Requests หรือ API Services เพื่อเล่นต้นแบบ

## กติกาการเดินและต่อสู้

- เส้นทางเดียวใช้ร่วมกันสองทิศ: ฝ่ายเราเริ่มที่ฐานและเดินไปหาแหล่งเกิดศัตรู
- ผู้เล่นเลือก **ชนิดตัวละคร** ไม่ต้องเลือกจุดวางป้อม การเรียกในระหว่างเวฟก็เริ่มจากฐานเสมอ
- แต่ละคนมีทีมได้ 12 ตัว และเริ่มต้น 900 เครดิต
- เมื่อเริ่มเวฟ ตัวละครในทีมทั้งหมดจะกลับมาที่ฐาน ฟื้นเลือดเต็ม แล้วทยอยออกเดินห่างกัน 0.6 วินาทีตามลำดับเรียก
- ตัวละครเลือกคู่ต่อสู้ที่ใกล้ที่สุดตามระยะบนเส้นทาง หยุดเมื่ออยู่ในระยะของตัวเอง และไม่เดินข้ามแนวศัตรู
- **Ember Ronin** เข้าประชิดเป็นแนวหน้า; **Frost Oracle** กับ **Astral Warden** หยุดโจมตีจากระยะไกล ศัตรูยังเดินเข้าหาได้จนถึงระยะของศัตรู
- ทั้งสองฝ่ายมีพลังโจมตีและ cooldown ศัตรูสามารถโค่นตัวละครเราได้
- ตัวละครที่ล้มจะหายจากสนาม แต่ยังอยู่ในรายชื่อทีมและยังรักษาระดับอัปเกรดไว้ กลับมาจากฐานในเวฟถัดไปโดยไม่เสียเงินเรียกใหม่
- อัปเกรดตัวละครที่ยังยืนอยู่จะเพิ่มเลือดตามส่วนต่างเลือดสูงสุด การอัปเกรดตัวที่ล้มไม่ทำให้ฟื้นกลางเวฟ
- ตัวละครที่เดินถึงประตูศัตรูจะรอและต่อสู้กับศัตรูที่เกิดใหม่ เป้าหมายของด่านนี้คือป้องกันฐาน ยังไม่มีระบบทำลายฐานศัตรู
- หลังศัตรูหมด เวฟพัก 12 วินาที กดเริ่มเวฟถัดไปก่อนหมดเวลาได้

## ตัวละคร

| ตัวละคร | ราคา | บทบาท | HP เริ่มต้น | ระยะ | ความสามารถ |
| --- | --- | --- | --- | --- | --- |
| Ember Ronin | 300 | ประชิด / แนวหน้า | 240 | 6 | โจมตีเร็ว เป้าหมายเดี่ยว |
| Frost Oracle | 400 | สนับสนุนระยะไกล | 170 | 19 | ลดความเร็วเคลื่อนที่ศัตรู 50% นาน 1.8 วินาที |
| Astral Warden | 550 | โจมตีหมู่ระยะไกล | 210 | 23 | ดาเมจเป็นกลุ่มในระยะเส้นทาง 10 studs รอบเป้าหมาย |

อัปเกรดได้ 4 ระดับ เพิ่มดาเมจและ HP ขายคืน 70% ของเงินเรียกและอัปเกรดที่ลงทุนไว้ ระยะโจมตีและความเร็วเดินของแต่ละสายคงเดิม

## สนามและการเล่นร่วมกัน

- **Lantern Valley**: หมู่บ้านโคมไฟ เส้นทางคดเคี้ยว ไม่มีจุดวางป้อม
- ศัตรู 8 เวฟ มีตัววิ่งเร็วและ **Rift Sovereign** ในเวฟสุดท้าย บอสมี HP และดาเมจสูงกว่า
- ฐานร่วมกัน 100 HP: ศัตรูทั่วไปถึงฐานเสีย 8 บอสเสีย 30
- การเรียก อัปเกรด ขาย เงิน HP การเคลื่อนที่และดาเมจคำนวณบนเซิร์ฟเวอร์
- แต่ละคนจัดการได้เฉพาะตัวละครของตนเอง รางวัลฆ่าศัตรูและจบเวฟให้ผู้เล่นทุกคนเต็มจำนวน
- ความเร็ว x1 / x2 เปลี่ยนได้โดยผู้เล่นคนแรกที่ยังอยู่ในเซิร์ฟเวอร์ มีผลต่อทั้งการเดิน การโจมตี และเวลาในด่าน
- หลังแพ้หรือชนะ ผู้เล่นที่ยังอยู่ทุกคนต้องโหวต **Replay** เพื่อเริ่มรอบใหม่ เงินและทีมจะรีเซ็ต
- เมื่อผู้เล่นออก ตัวละครของคนนั้นจะถูกลบ ถ้าทุกคนออกจะรีเซ็ตด่าน

## แก้ไขและสร้างไฟล์เกม

- `src/Config.lua`: ราคา HP ความเร็วเดิน ดาเมจ ระยะ อัปเกรด และค่าศัตรูแต่ละเวฟ
- `src/Server.server.lua`: สร้างฉาก/ตัวละคร การเดินสองฝ่าย การต่อสู้ เลือด การฟื้น และการตรวจคำสั่ง
- `src/Client.client.lua`: เมนูเรียก/เลือกทีม ข้อมูลตัวละคร กล้อง วงระยะ เอฟเฟกต์ และอินพุต
- `default.project.json`: การจัด service สำหรับผู้ที่ใช้ Rojo อยู่แล้ว

สร้างไฟล์ place และ ZIP ที่บรรจุ source ปัจจุบันใหม่:

```sh
cd /workspace/paid/roblox/anime-mysterious
python3 tools/build_place.py
```

ใช้ Python standard library เท่านั้น ตัวแพ็กตรวจ XML และตรวจว่า source ของ Script / LocalScript / ModuleScript อ่านกลับมาตรงกับไฟล์ต้นฉบับ จากนั้นสร้าง `../AnimeMysterious.zip` และตรวจเนื้อหาทุกไฟล์ใน ZIP

หากแก้ใน Roblox Studio โดยตรง ให้บันทึก place แยกก่อน เพราะตัวแพ็กจะสร้าง place จากไฟล์ใน `src/` ใหม่

## การตรวจสอบ

ตรวจใน cloud ด้วย syntax parser และรัน source เซิร์ฟเวอร์จริงผ่าน Fengari พร้อม service จำลอง:

- การเรียกโดยไม่มีจุดวาง การตรวจชนิด input เงิน สิทธิ์เจ้าของ อัปเกรด เงินขายคืน จำนวนสมาชิกทีม และอัตราคำสั่ง
- ตัวละครเริ่มที่ฐานเรา ระยะทางลดลงเมื่อเดินออกไป และเข้าโจมตีศัตรู
- ทั้งสองฝ่ายโจมตีได้ ตัวละครเราเสียเลือด ล้ม และถูกนำออกจากสนาม
- อัปเกรดตัวละครที่ล้มไม่ทำให้ฟื้นกลางเวฟ และเวฟถัดไปฟื้นที่ฐานพร้อมระดับอัปเกรดเดิม
- ตัวที่เรียกกลางเวฟเริ่มเดินจากฐาน ไม่เกิดกลางสนาม
- ศัตรูหลุดถึงฐาน การแพ้/ชนะ โหวตเริ่มใหม่ และการเก็บกวาดเมื่อผู้เล่นออก
- จำลองกลยุทธ์ solo ด้วยค่าสเตตัสที่ส่งมอบ ครบ 8 เวฟ: ฐานเหลือ 100 HP ในการทดสอบปัจจุบัน

การทดสอบ lifecycle แยกต่างหากเพิ่มดาเมจชั่วคราวเพื่อเร่งการเปลี่ยนสถานะ และการทดสอบการล้มเพิ่มดาเมจศัตรูเฉพาะหน่วยความจำของการทดสอบ ค่าพวกนี้ไม่ถูกบันทึกในไฟล์เกม การจำลอง solo ใช้ค่าปกติทั้งหมด

**ยังไม่ได้ทดสอบด้วย Roblox Studio จริง** เครื่อง cloud ไม่มีเอนจิน Roblox การจำลองไม่ตรวจ rendering, การหมุนโมเดล/ท่าเดิน, replication, UI หรืออินพุตจริง และยังไม่ยืนยันความสนุกหรือสมดุลกับผู้เล่นจริง

รายการที่ต้องตรวจใน Studio ก่อนเผยแพร่:

1. Play แล้วดู Output ไม่มี error เห็นตัวละครมีหัว/แขน/ขารอที่ฐานเรา
2. เรียก Ronin 3 ตัว แล้วเริ่มเวฟ: เห็นเดินจากฐานสีเขียวไปตามเส้นทางและศัตรูเดินสวนจากประตูม่วง
3. เห็นหยุดสู้และเสียเลือด ไม่เดินทะลุแนวรบ ตรวจท่าเดิน การหันหน้า และอาวุธ
4. ทดสอบตัวละครล้ม แล้วเลือกผ่าน < / > และเริ่มเวฟถัดไป: กลับจากฐานพร้อมอัปเกรดเดิม
5. เรียกเสริมระหว่างเวฟ: ต้องออกจากฐานเรา ไม่ปรากฏที่จุดคลิก
6. เลือกตัวละครที่เดินอยู่: วงระยะและข้อมูลติดตาม อัปเกรด/ขายทำงาน
7. Device Emulator และ Start Server สองผู้เล่น: UI, touch, HP, เวฟ, ความเป็นเจ้าของและโหวตตรงกัน
8. ตรวจครบรอบบอส ชนะ/แพ้ และเริ่มใหม่

รันการตรวจจำลองบน cloud เครื่องนี้:

```sh
NODE_PATH=/workspace/setup-validation/roblox-tools/node_modules node tests/validate.cjs
```

เครื่องอื่นติดตั้ง `luaparse@0.3.1` และ `fengari@0.1.5` ในโฟลเดอร์เครื่องมือแยก แล้วตั้ง `NODE_PATH` ไปยัง `node_modules` นั้น

## ขอบเขตต้นแบบ

โมเดลเป็นตัวละครบล็อกต้นฉบับและท่าเดินที่ขยับชิ้นส่วน ยังไม่มี rig/แอนิเมชันจากศิลปิน ความสามารถกดใช้ ล็อบบี้ คลัง/สุ่มตัวละคร DataStore หรือร้านค้า เงินและทีมอยู่เฉพาะรอบปัจจุบัน จำนวนศัตรูและ HP ยังไม่เพิ่มตามจำนวนผู้เล่น ต้องทดสอบสมดุล co-op แยกก่อนนำไปใช้จริง
